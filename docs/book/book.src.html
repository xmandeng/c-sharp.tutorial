1 What C# and .NET Are

C# is a statically typed, object-oriented language from Microsoft, first released in 2002. "Statically typed" means every variable's type is fixed and checked when the program is compiled, before it runs. .NET is the platform that compiles and runs C# code. People often say "C#" and ".NET" as if they were one thing; in an interview, use "C#" for the language and ".NET" for everything around it.

The table lists the five parts of .NET that interviewers name, with the nearest Python equivalent of each.

1.2  How a C# Program Runs

C# is compiled in two steps, and the first step catches most mistakes. dotnet build runs the C# compiler, which checks every type in every file and refuses to produce output if any check fails. The output is a .dll file of IL (Intermediate Language), a CPU-independent instruction set. While the program runs, the CLR's JIT (just-in-time) compiler turns each method's IL into machine code for the current CPU the first time the method is called.

Python finds a type mistake only when the faulty line runs. C# finds it before the program can start. This is the largest practical difference between the two languages, and the reason C# code contains so many type names.

Figure 1. Python checks types while running; C# checks them before running.

1.3  .NET versus .NET Framework

Two products share the name, and job descriptions mix them up.

  • .NET Framework (versions 1.0 to 4.8) is the original, Windows-only platform. It receives security fixes but no new features. Many company codebases still run on it.
  • .NET (formerly .NET Core; versions 5, 6, 7, 8, 9, 10) is the cross-platform rewrite. It runs on Windows, Linux and macOS. All new work targets it. Even-numbered versions are LTS (long-term support) releases.

The companion project uses .NET 10, the LTS release from November 2025, with C# 14. A codebase "on Framework" uses older syntax, such as explicit Main methods and namespace blocks in braces. Section 3.2 shows both styles.

2.4  Program.cs Walkthrough

It uses syntax from later chapters (foreach, switch, the ? : conditional, LINQ's Select); skim it now and return to it after chapter 10. It uses top-level statements: code written directly in the file, with no class around it. The compiler wraps it in a hidden class and Main method. Only one file per project may do this.

:::cs Tutorial/Program.cs (abridged) using Tutorial; var titles = new Dictionary { [1] = "Hello, C#", [2] = "Types and variables", // ... chapters 3 to 11 ... }; // args is the command-line arguments, like Python's sys.argv[1:] IEnumerable toRun = args.Length > 0 ? args.Select(int.Parse) : titles.Keys; foreach (int chapter in toRun) { Console.WriteLine($"\n=== Chapter {chapter}: {titles[chapter]} ==="); switch (chapter) { case 1: Ch03Basics.Run(); break; // ... case 10: await Ch12Async.RunAsync(); break; case 11: Ch13Orders.Run(); break; } } :::

  • titles.Keys runs every chapter when no argument is given.
  • C# does not let one case fall through into the next, so each one ends in break (or return or throw).

3 Syntax Basics

C# uses C-style syntax. Braces mark blocks, semicolons end statements, and names are case-sensitive. Indentation is ignored by the compiler but kept by convention. Run this chapter with dotnet run --project src/Tutorial -- 3.

3.1  A First Program

:::file src/Tutorial/Ch03Basics.cs :: namespace Tutorial; :: public static class Ch03Basics

The same program in Python:

:::py import math def run(): print("Hello, C#!") name = "Ada" year = 1843 print(f"{name} wrote the first program in {year}.") print(f"pi to 2 places: {math.pi:.2f}") if year < 1900: print("That was a long time ago.") :::
  • namespace Tutorial; puts everything in the file into the Tutorial namespace. A namespace is a dotted name, such as Tutorial.Orders, that becomes part of the full name of every type declared in it, like a Python package path.
  • public static class is a class that holds only static methods and fields and cannot be instantiated. It is the closest thing C# has to a Python module of plain functions.
  • public static void Run() declares a method. void means it returns nothing (Python: -> None).
  • string name = "Ada"; declares the variable's type before its name.
  • $"...{name}..." is an interpolated string, the C# version of an f-string.
  • Strings use double quotes only. Single quotes hold one character: 'A' is a char.

3.2  The Older Style

Code written before 2021, and all .NET Framework code, spells out a namespace block, a class and a Main method, all of which modern C# lets you leave out. The program below is the same "hello" in that style.

:::cs using System; namespace Tutorial { class Program { static void Main(string[] args) { Console.WriteLine("Hello, C#!"); } } } :::

static void Main(string[] args) is the entry point: the method the runtime calls first. It plays the role of Python's if __name__ == "__main__": block. The namespace wraps the class in braces instead of ending in a semicolon. Both styles compile to the same program.

4 Types and Variables

Every C# variable has one type for its whole life, and the compiler rejects any assignment that does not fit. In Python, x = 3 followed by x = "three" is legal. In C#, int x = 3; followed by x = "three"; does not compile. File: src/Tutorial/Ch04Types.cs.

Use decimal for money, as the order system in chapter 13 does. A double cannot store 0.1 exactly, so sums of prices drift by tiny amounts.

4.2  var

var tells the compiler to work out the type from the right-hand side. The variable is still statically typed. var saves typing; it does not make the variable dynamic.

:::file src/Tutorial/Ch04Types.cs :: var total ..> Console.WriteLine($"total is :::out total is an Int32 :::

Int32 is the .NET name for int; int is the C# keyword for it. Most teams use var when the type is obvious from the line, such as var names = new List<string>();.

4.3  Conversions

C# converts between number types automatically only when the conversion is considered safe, such as int to long or int to double. A conversion that can lose information, such as double to int, must be written out.

:::file src/Tutorial/Ch04Types.cs :: int parsed ..> Console.WriteLine($"{parsed} :::out 42 False 0 3 3 :::
  • int.Parse("42") is Python's int("42"). It throws an exception on bad input.
  • int.TryParse(text, out int maybe) returns true or false instead of throwing, and writes the number into maybe. This TryX pattern appears all over .NET. Section 7.3 explains out.
  • (int)3.99 is a cast: an explicit conversion. It truncates to 3.
  • 7 / 2 is 3, because both sides are int. Python's / would give 3.5.

4.4  Value Types and Reference Types

Every C# type is either a value type or a reference type, and the two behave differently on assignment. This is the single most common C# interview question.

  • A value type variable holds the data itself. Assigning it copies the data. Value types: all number types, bool, char, struct, enum.
  • A reference type variable holds the address of an object. Assigning it copies the address, so both variables point at one object. Reference types: class, record, string, arrays, List, interfaces.

Python has only the second kind: every Python variable is a reference.

:::file src/Tutorial/Ch04Types.cs :: int a = 1; ..> Console.WriteLine($"listA.Count :::out a = 1, b = 99 listA.Count = 3 :::

Figure 3. Assigning a value type copies the data; assigning a reference type copies only the address, so both variables point at one object.

4.5  null

null means "no object", like Python's None. A type name followed by ? marks a variable that is allowed to hold null.

:::file src/Tutorial/Ch04Types.cs :: int? missing ..> Console.WriteLine(maybeName :::out -1 0 :::
  • int? is an int that may also be null (Python: Optional[int]).
  • int? and string? look alike but work differently. int? is a separate type, Nullable<int>, with .HasValue and .Value. string? is only a note to the compiler: at run time any string variable can hold null, and the ? controls which warnings you get.
  • x ?? y gives x, or y if x is null. Python's x if x is not None else y.
  • x?.Length gives null instead of crashing when x is null.
  • With <Nullable>enable</Nullable> in the project file, the compiler warns when a string without ? might receive null. These are nullable reference types. They are warnings, not errors.
  • Using a null reference throws NullReferenceException, the C# version of AttributeError: 'NoneType' object has no attribute ....

6.3  Generics

A generic type is a type with a placeholder for another type, written in angle brackets. List<T> is written once; List<string> and List<int> are two concrete types made from it. Python's list[str] hint looks the same but is never enforced. C# enforces it at compile time, and the type argument still exists at run time.

You can write your own generic methods and classes. <T> after the method name declares the placeholder, and the caller's argument types fill it in:

:::cs public static T FirstItem(List items) { return items[0]; } string name = FirstItem(new List { "Ada", "Grace" }); // T is string int score = FirstItem(new List { 90, 72 }); // T is int :::

A where clause limits what T may be. For example, where T : IShape accepts only types that implement the IShape interface (chapter 9).

7 Methods

A method is a function that belongs to a class. C# has no free-standing functions; even utility functions live in a static class. File: src/Tutorial/Ch07Methods.cs.

7.1  Anatomy of a Signature

:::file src/Tutorial/Ch07Methods.cs :: public static int Add(int a, int b)

  • int: the return type. Every return path must return an int.

7.2  Access Modifiers and static

An access modifier states which code may use a class member. The compiler enforces it.

ModifierWho can use the member
publicAny code.
privateOnly code inside the same class. The default for class members.
protectedThe same class and its subclasses.
internalAny code in the same project (assembly). The default for classes.

static is not an access modifier. A static member belongs to the class itself: one copy shared by all objects, used without creating an object. A non-static (instance) member belongs to each object. In Python terms, static methods are @staticmethod, and static fields are class attributes.

7.3  Parameters

:::file src/Tutorial/Ch07Methods.cs :: public static string Greet ..> public static void Double

The calls, from Run:

:::file src/Tutorial/Ch07Methods.cs :: Console.WriteLine(Greet("Ada")); ..> Console.WriteLine($"value is now
  • Default values work as in Python: string greeting = "Hello".
  • Named arguments use a colon: Greet("Ada", greeting: "Welcome").
  • out marks a parameter the method must fill in. The caller writes out int quotient and gets the value back. It exists because C# methods historically returned only one value.
  • Tuples are the modern way to return several values, as in Python. var (lo, hi) = MinMax(...) unpacks them.

7.4  Lambdas, Func and Action

A lambda is an unnamed function written parameters => expression. Python writes lambda x: x * 3; C# writes x => x * 3. A C# lambda may also have a braced body with several statements, which Python lambdas cannot.

:::file src/Tutorial/Ch07Methods.cs :: Func triple ..> shout("done")

A variable that holds a function has a delegate type: a type that states the function's parameter types and return type. Func<int, int> takes an int and returns an int; the last type argument is always the return type. Action<string> takes a string and returns nothing.

8 Classes, Records and Structs

C# offers three ways to define your own type. A class is the default. A record is for data compared by value. A struct is a small value type. File: src/Tutorial/Ch08Classes.cs.

8.1  A Class: BankAccount

BankAccount shows encapsulation, which means a class keeps its data private and lets outside code change it only through methods that check each change. Outside code can read the balance but can change it only through Deposit and Withdraw.

:::file src/Tutorial/Ch08Classes.cs :: public class BankAccount

The same class in Python, for comparison:

:::py class BankAccount: _next_id = 1 # class attribute def __init__(self, owner: str, opening_balance=Decimal("0")): if not owner or not owner.strip(): raise ValueError("Owner is required.") self.owner = owner self.id = f"ACC-{BankAccount._next_id:04d}" BankAccount._next_id += 1 self._balance = opening_balance @property def balance(self) -> Decimal: return self._balance def deposit(self, amount: Decimal) -> None: if amount <= 0: raise ValueError("Deposit must be positive.") self._balance += amount def __str__(self) -> str: return f"{self.id} {self.owner}: {self.balance:.2f}" :::

8.2  Reading the Class

  • Field: a variable stored in each object. private decimal _balance; Fields are normally private.
  • Property: a member that looks like a field from outside but runs code on read or write. public string Owner { get; } can be read by anyone and set only in the constructor. public decimal Balance => _balance; is computed on each read, like @property. Public data in C# is exposed through properties, not public fields.
  • Constructor: the method with the class's name and no return type. It is __init__. There is no self parameter; members are in scope directly, and this refers to the current object when you need it.
  • nameof(owner) produces the string "owner". If the parameter is renamed and nameof is not, the build fails, so the text cannot go out of date.
  • override string ToString() replaces the default text form, as __str__ does. Console.WriteLine(account) calls it.

Property forms you will meet in real code:

:::cs public string Name { get; set; } // anyone reads and writes public string Name { get; private set; } // anyone reads; only this class writes public string Name { get; } // set only in the constructor public string Name { get; init; } // set in constructor or object initializer public string Name => _name; // computed on every read :::

8.4  Records

A record is a class designed to hold data, with value equality: two records are equal when all their properties are equal. One line declares the properties, the constructor, equality and a readable ToString. It matches Python's @dataclass(frozen=True).

:::file src/Tutorial/Ch08Classes.cs :: public record Point(int X, int Y); :: var p1 ..> Console.WriteLine(g1 == g2) :::out True Point { X = 1, Y = 2 } Point { X = 10, Y = 2 } False :::

p1 == p2 is True because records compare contents. g1 == g2 is False because classes compare identity: two separate objects are never equal unless the class overrides equality. Python's == on plain classes also compares identity.

with makes a copy with some properties changed, like dataclasses.replace.

A struct is a value type you define yourself (section 4.4). Assigning one copies all of its data. Structs suit small values such as coordinates or temperatures.

new Temperature { Celsius = 20 } is an object initializer: it creates the object, then sets each listed property. It works for classes too.

A class may inherit from one base class and implement any number of interfaces. An interface is a named list of method and property signatures that a class must implement; it holds no stored data. Code that accepts the interface works with every class that implements it. File: src/Tutorial/Ch09Interfaces.cs.

9.3  Polymorphism

Polymorphism means one call runs different code depending on the object's actual class. TotalArea accepts any sequence of IShape objects and calls Area() on each. Each object runs its own class's Area().

10 LINQ

LINQ (Language Integrated Query) is a set of methods for filtering, transforming, sorting and grouping collections. It does the work of Python's list comprehensions, sorted, sum, any and itertools. Most LINQ methods take a lambda. Deferred execution means a LINQ query does not run when you write it; it runs each time you loop over it. It is lazy like a Python generator expression, with one difference: a generator is used up after one loop, while a LINQ query runs again on every loop.

:::file src/Tutorial/Ch10Linq.cs :: // Deferred execution ..> Console.WriteLine($"evens

The output is 2,4: the 4 was added after the query was written, but before it ran. Two consequences matter in practice:

  • Looping over the same query twice runs it twice. Call .ToList() to run it once and keep the result.
  • IEnumerable<T>, the type a query returns, means "something you can loop over". It does not mean the items exist yet. A List<T> holds them in memory.

Entity Framework, the standard database library, uses IQueryable<T>. The same LINQ methods are translated into SQL and run in the database instead of in memory.

12 Async and Await

async and await let a method wait for slow input or output (a web request, a database query, a file) without blocking a thread. The keywords and their purpose match Python's asyncio. File: src/Tutorial/Ch12Async.cs.

12.1  Walkthrough

:::file src/Tutorial/Ch12Async.cs :: public static async Task FetchAsync :: public static async Task RunAsync :::out sequential took ~600 ms concurrent took ~300 ms first finished after 300 ms second finished after 300 ms A finished after 300 ms B finished after 300 ms :::
  • Task<string> is an object that represents an operation in progress; when the operation finishes, the task holds its string result. Task without a type argument returns nothing. Python's closest equivalent is an asyncio.Task from asyncio.create_task, which also starts running at once.
  • await pauses this method until the task finishes, and frees the thread for other work meanwhile.
  • Task.WhenAll(a, b) waits for both. It is asyncio.gather.
  • By convention, async method names end in Async.

12.2  Differences from Python

  • Calling an async method starts it. FetchAsync("A", 300) begins running at once and returns a running Task. A Python coroutine does nothing until it is awaited or scheduled. This is why lines a and b above run at the same time.
  • No event loop to start. There is no asyncio.run(). Main (or top-level code) can itself use await.
  • Real threads. After an await, the method may continue on a different thread-pool thread. For CPU-heavy work, Task.Run(() => ...) runs code on another thread, and threads run in parallel.

12.3  Rules Interviewers Check

  • Do not call .Result or .Wait() on a task. Both block the thread until the task ends, which wastes the thread and can deadlock in UI and older ASP.NET apps. Use await.
  • Do not write async void methods, except for event handlers. A caller cannot await them, and their exceptions crash the process. Return Task.
  • Callers of an async method usually become async too, so that they can await it. This is normal.

13.4  Dependency Injection

Dependency injection (DI) means a class receives the objects it works with through its constructor instead of creating them. OrderService receives an Inventory and an IDiscountPolicy. It never writes new BulkDiscount() itself.

16 Interview Quick Reference

Each answer below is short enough to say aloud. Each one points to the example in the companion project that you can describe.

16.1  Likely Questions

What is the difference between a value type and a reference type?

A value type variable holds its data, and assignment copies it: numbers, bool, struct. A reference type variable holds a reference to an object, and assignment copies the reference, so two variables can share one object: classes, records, strings, arrays, lists. (Section 4.4.)

Class, struct or record?

A class is a reference type compared by identity, for objects with behaviour and state. A record is a reference type compared by value, for data. A struct is a value type, for small values. In the project, BankAccount is a class, Receipt a record, Temperature a struct.

Interface or abstract class?

A class can implement many interfaces but inherit only one class. An interface lists members that implementing classes must provide, and holds no stored data. An abstract class shares code and fields among related classes. I would use IDiscountPolicy as the interface example and Shape as the abstract class.

What do abstract, virtual and override mean?

abstract: no body here, subclasses must provide one. virtual: has a body, subclasses may replace it. override: this subclass method replaces the parent's. A method without virtual or abstract cannot be overridden.

What are the four pillars of object-oriented programming?

Encapsulation: a class guards its own data (BankAccount._balance is private; changes go through Deposit). Abstraction: callers call one public method and do not see the steps inside it (Checkout). Inheritance: a class reuses a parent's code (Square : Rectangle). Polymorphism: one call runs different code per type (shape.Area()).

What is SOLID?

Five design rules. Single responsibility: one reason to change per class. Open/closed: add behaviour with new code, not edits (a new IDiscountPolicy). Liskov substitution: a subclass must work wherever its parent is expected. Interface segregation: small, focused interfaces. Dependency inversion: depend on interfaces, not concrete classes (OrderService takes IDiscountPolicy).

What is dependency injection, and what are the lifetimes?

A class receives the objects it uses through its constructor instead of creating them, which makes them swappable and testable. ASP.NET Core's container creates them for you. Singleton: one for the app. Scoped: one per request. Transient: new each time. (Sections 13.4 and 14.1.)

What is LINQ, and what is deferred execution?

LINQ is a set of methods, such as Where, Select and GroupBy, for querying any collection. A query runs when you loop over it, not when you write it. ToList() runs it once and stores the result. Against a database, EF Core translates the same query into SQL. (Chapter 10.)

IEnumerable versus List?

IEnumerable<T> is an interface meaning "can be looped over"; it may be a lazy query. List<T> is a concrete in-memory collection with indexing and Add. Accept IEnumerable in parameters when you only loop, as TotalArea does.

How do async and await work?

An async method returns a Task. await pauses the method until the task finishes, releasing the thread meanwhile, so a server can handle other requests while waiting on I/O. Use Start several tasks, then await Task.WhenAll(...) to wait for all of them. Avoid .Result, .Wait() and async void. (Chapter 12.)

How is memory managed? What is IDisposable?

A garbage collector frees objects that nothing references. It runs at times you do not control. IDisposable and using release resources such as files and database connections at a known point, the way Python's with does. (Section 11.3.)

const, readonly and static?

const: a value fixed at compile time, such as TaxRate. readonly: a field assigned once, in the constructor, such as OrderService._inventory. static: belongs to the class, not to each object.

== versus Equals?

For classes, == compares identity unless the class overrides it. Records and string override it to compare contents, so "a" == "a" is true. Equals is the method form, which types override to define value equality.

Why is string immutable, and what is StringBuilder?

A string never changes; every edit makes a new string, as in Python. Immutability makes strings safe to share between threads and to use as dictionary keys. Building a long string with += in a loop copies it every time. StringBuilder appends into one buffer, like collecting parts in a list and calling "".join(parts).

What are generics?

Types and methods with a type placeholder, such as List<T>. One definition works for many types and stays type-checked. where T : IShape restricts what T can be.

What are delegates and events?

A delegate is a type for a function reference; Func and Action are the built-in ones, and a lambda can be assigned to one. An event is a delegate field that outside code can only subscribe to with += or unsubscribe from with -=; the owning class calls the subscribers when something happens. Events are common in UI code. Python's closest match is passing callback functions.

How would you test this class?

With xUnit: one [Fact] per behaviour, each following arrange, act, assert. Pass fake dependencies through the constructor; a library such as Moq creates them from interfaces. OrderServiceTests is the example.
